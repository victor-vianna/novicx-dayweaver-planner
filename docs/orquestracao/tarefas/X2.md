# X2 — A11y do menu mobile

- **Dono:** Codex executor · **Revisão:** Claude · **Base:** `claude/ciclo-3` · **Faixa:** `src/components/layout/**`, `*.test.tsx` novos em `src/components/layout/`, `docs/ENTREGA-CODEX.md`

## Objetivo

Menu mobile do `AppFrame` acessível por teclado e leitor de tela, sem mudar o visual.

## Critérios de aceite

1. Botão que abre/fecha o menu tem `aria-label` em pt-BR, `aria-expanded` e `aria-controls` corretos.
2. Com o menu fechado, o painel fica fora da ordem de tabulação e da árvore de acessibilidade (`inert` ou equivalente); aberto, o foco vai para o painel.
3. `Esc` fecha o menu e devolve o foco ao botão.
4. Teste de componente cobrindo 1–3; visual e comportamento desktop inalterados.

## Testes

`npx vitest run --maxWorkers=2 src/components/layout`, `npx tsc --noEmit`, `npm run lint`.
