# F1 — Jornada E2E completa no dev

- **Dono:** Claude · **Revisão:** dispensada (FILA, 2026-10-25) · **Depende:** T8 · **Faixa:** `src/services/supabase/accounts.it.ts`, `scripts/lib/e2e-setup-sql.ts` (pacote `b3` da cliente fixa `c3`)

## Objetivo

Um cenário automatizado percorre o produto inteiro no projeto dev, com limpeza que falha a suíte.

## Abordagem

`accounts.it.ts` vira a jornada: admin cria (1ª execução) ou renova o acesso da `c3` → link de senha → a cliente define a senha e entra → admin cria rascunho, envia carrossel (invisível para a cliente) e libera → a cliente vê, baixa uma arte (URL assinada, `Origin` do app, `image/jpeg`) e confirma a publicação → o histórico registra `created, media_added×2, status, status`, a última com a cliente como ator, e a cliente não lê o histórico → admin bloqueia: cadastro, post e arquivo somem na hora, refresh e login falham → admin desbloqueia e o acesso volta. Limpeza: volta o post para rascunho, `deletePost` (falha se sobrar arquivo) e confere a pasta vazia.

## Critérios de aceite

1. Cenário verde no dev; limpeza com falha explícita.
2. Sem resíduo: 0 posts, mídias, eventos e objetos E2E; usuários inalterados (4 E2E + 1); conta `c3` ativa.
